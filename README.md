# Smiski (Glow-in-the-Dark Renderer)
Small renderer application built using OpenGL. This renders objects to look like a glow-in-the-dark Smiski figurine. 

My inspiration behind this project is the two Smiski figures I have on my desk. One night, I found myself wondering if I could recreate the lovely glow they emitted when I turned my desk lamp off, so as a way to practice my shader writing skills and as an introduction to the OpenGL framework, I decided to create this small renderer.

Since this was created as an introduction to OpenGL, my main focus is on the visuals of the glow-in-the-dark effect instead of turning this into a full-blown OpenGL rendering engine. If I have time in the future, I may revisit this project and expand its capabilities.
